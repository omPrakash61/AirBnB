AirBnB Clone - Web App

A full-stack AirBnB-inspired web application where You can sign up, log in, create listings, and book stays — all powered by Node.js, Express, EJS, and MongoDB Atlas.

Live Demo 
https://airbnb-yac3.onrender.com

Features
🔐 User Authentication with Sessions
🏘️ Add, Edit, and Delete Listings
🔍 Search Listings by Location, Title, or Country
🗂️ View Individual Listing Details
📅 Book Stays with Booking Info Summary
🎨 EJS Templating and Static Assets (CSS, JS)
☁️ Deployment using MongoDB Atlas (Free Tier) & Render

Tech Stack

Frontend  
- CSS, JS  
- EJS Templating Engine  

Backend
- Node.js  
- Express.js  
- express-session  
- Mongoose (MongoDB ODM)

Database
- MongoDB Atlas (Free Tier)

Deployment
- Backend: Render  
- Database: MongoDB Atlas
